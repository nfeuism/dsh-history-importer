GET STARTED

三步开始

首次使用请先启动一次 DeepSeek Harness 完成初始化，然后完全退出应用。

01

取得程序

Mac 用户下载对应芯片的压缩包；Windows 用户下载可执行文件。

前往下载 →
02

预览对话

Mac 解压后双击 Start-Import.command，选择 1 查看数量。预览不会写入文件。

Mac 菜单：1 · 预览
03

导入并查看

完全退出 Harness 后选择 2 导入；重新打开，在侧栏找到两个历史项目。

Mac 菜单：2 · 导入
Windows 命令在 PowerShell 中运行 .\dsh-history-importer.exe 预览，运行 .\dsh-history-importer.exe --import 导入。源码运行方式见 README。

GOOD TO KNOW

使用前了解这些

支持哪些来源？

首版支持本机 Codex 和 Hermes Agent 的历史对话。可只选择其中一个来源。

Mac 安装包如何打开？

下载对应芯片的压缩包，解压后双击 Start-Import.command。程序未经 Apple 开发者证书公证；首次打开可能需要在系统提示中确认。

会覆盖已有会话吗？

不会。相同会话使用固定 ID，重复运行会跳过；修改项目登记文件前保留备份。

其他 Harness 版本能用吗？

当前按 0.2.0-rc.2 的会话格式制作。Harness 更新后，先查看仓库中的兼容说明。
